# 210万分の1

新潟県で2027年に生まれるひとりの一生を、統計の頻度にそって0歳から最期まで進めるライフシミュレーターです。『80億分の1』へのオマージュとして作りました。

- `index.html` — ゲーム本体(1ファイル)。公開版: https://claude.ai/artifact/DMCzJJ5BMKdgXzZQA5qxNy
- `sim.js` — 検証用。ノードで数千人分を自動実行し、平均寿命・災害の頻度・分岐を確認します。

```bash
node sim.js index.html 4000
```

数字は公的統計と仮定を組み合わせた試算で、個人の将来の予測ではありません。就職先の企業名は実在する企業の例で、ゲーム内の年収や出来事はその企業の実際とは関係ありません。
